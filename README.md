# PDF Studio

A simple browser-based PDF editor.

**Developed by Sohel** · GitHub: [@sohel1807](https://github.com/sohel1807)

## How to use

1. Choose a PDF or drag it onto the upload screen.
2. Select **Edit text** to replace text, or **Fill blank area** to add text.
3. Preview your changes, then download the edited PDF.
4. Use **Delete PDF** to remove the uploaded document.

## Features

- Browse pages and select text to edit.
- Add text to blank areas and adjust its font, size, color, and alignment.
- Preview edits and undo or redo changes.
- Keep the original PDF unchanged; edits are saved as a new download.
- Stored uploads are cleaned up automatically.

Scanned and password-protected PDFs are not supported. PDF Studio is not intended for secure redaction.
